# 100 Days Data Analytics Practice

Daily practice repository covering SQL, Python, Statistics, and Business Analytics case studies.

## Goal

Strengthen problem-solving skills for Data Analyst and Product Analytics roles through consistent hands-on practice.

## Tech Stack

* SQL
* Python (Pandas, NumPy)
* Statistics
* Power BI / Tableau concepts

## What each day contains

* Problem statement
* Dataset / schema
* Solution
* Explanation
* Key learning

## Current Target

* 100 SQL problems
* 50 Python problems
* 20 Statistics problems
* 10 Business case studies
